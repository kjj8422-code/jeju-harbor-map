# 3D 모델 넣는 법

지금 게임의 나무·성벽·사람은 **도형으로 만든 임시 형태**입니다.
업계에서는 이걸 그레이박싱이라고 부르고, 정식 개발에서도 똑같이 합니다 —
**모델이 도착하기 전까지 자리만 잡아두는 것**입니다.

이 폴더에 `.glb` 파일을 넣으면 그 자리가 진짜 모델로 바뀝니다. **코드는 한 줄도 안 고칩니다.**

---

## 1. 어디서 구하나 (무료 · 상업 이용 가능)

| 사이트 | 무엇이 있나 | 라이선스 |
|---|---|---|
| **kenney.nl/assets** | 저폴리 건물·자연·캐릭터 묶음. 초보자에게 가장 쉬움 | CC0 (완전 자유) |
| **quaternius.com** | 캐릭터 + **애니메이션 포함**, 판타지·자연·중세 | CC0 |
| **poly.pizza** | 저폴리 모델 검색 | 대부분 CC0 / CC-BY |
| **sketchfab.com** | 종류가 가장 많음 (필터에서 "Downloadable" + 라이선스 선택) | 모델마다 다름 |
| **mixamo.com** (어도비) | 캐릭터 **모션** — 걷기·공격·구르기·죽음 | 무료 계정 필요 |

> ⚠️ **라이선스는 반드시 직접 확인하세요.** 나중에 수익을 내실 거라 더 중요합니다.
> - **CC0** — 표기 없이 상업적으로 자유롭게 사용 (가장 안전)
> - **CC-BY** — 사용은 자유지만 **출처를 표기**해야 함
> - **비상업(NC)** — 돈 버는 게임에는 **쓰면 안 됩니다**
>
> 받은 파일의 라이선스와 출처를 `models/CREDITS.txt` 같은 파일에 적어두세요.
> 나중에 "이거 어디서 받았지?"를 못 찾으면 곤란해집니다.

## 2. 파일 형식

**`.glb`** 를 받으세요. (`.gltf` + 별도 텍스처 묶음도 되지만 `.glb` 한 파일이 가장 편합니다)

`.fbx`나 `.obj`만 있다면 **Blender**(무료)로 열어서 `File → Export → glTF 2.0 (.glb)` 로 내보내면 됩니다.

## 3. 넣는 법 (3단계)

1. `.glb` 파일을 이 폴더(`models/`)에 넣습니다
2. `manifest.json` 을 열어 아래처럼 적습니다

```json
{
  "tree":       { "file": "tree.glb",   "height": 3.2 },
  "rock":       { "file": "rock.glb",   "height": 0.9 },
  "hero_sword": { "file": "hero.glb",   "height": 1.8 },
  "monster":    { "file": "grunt.glb",  "height": 1.7 }
}
```

3. 새로고침

`height` 는 **게임 안에서의 키(미터)** 입니다. 받아온 모델은 크기가 제각각이라
(어떤 건 0.01, 어떤 건 500) 이 값으로 자동 조정합니다. 사람은 1.7~1.8 이 적당합니다.

## 4. 바꿀 수 있는 자리 목록

| 열쇠말 | 무엇 | 권장 height |
|---|---|---|
| `tree` | 나무 | 3.0 ~ 3.6 |
| `rock` | 바위 | 0.8 ~ 1.1 |
| `iron` | 철광 | 0.9 |
| `base` | 거점(성채) | 8 ~ 10 |
| `wall` | 목책 한 칸 | 1.2 |
| `trap` | 가시함정 | 0.5 |
| `camp` | 병영 | 2.0 |
| `forge` | 대장간 | 2.0 |
| `hero_sword` / `hero_bow` / `hero_halberd` | 장수 (무기별) | 1.8 |
| `soldier` | 병사 | 1.6 |
| `monster` | 황건적 졸개 | 1.7 |
| `boss` | 산적 두목 | 3.0 |

**전부 넣을 필요 없습니다.** 하나만 넣어도 그 자리만 바뀌고 나머지는 그대로 도형으로 나옵니다.
나무 하나만 바꿔도 화면이 확 달라지니 거기서 시작하시길 권합니다.

## 5. 주의

- **파일 크기** — `.glb` 하나가 5MB를 넘으면 로딩이 느려집니다. 저폴리 모델은 보통 100KB 안쪽입니다.
- **폴리곤 수** — 나무처럼 여러 개가 동시에 나오는 것은 **1,000 삼각형 이하**를 고르세요.
  하나에 5만 개짜리 고품질 나무를 120그루 놓으면 어떤 컴퓨터도 버티지 못합니다.
- **애니메이션** — 지금은 모델의 모션을 재생하지 않습니다. 필요해지면 그때 붙이겠습니다.
